# 🌟 **О проекте**:  

*Обращаю внимание, проект находится в стадии разработки!*
 
Cosmic Slpway - мобильное приложение под IOS, предназначено для игроков мобильной игры [Eve Echoes ](https://www.eveechoes.com).
Оно позволяет конфигурировать корабль с учетом доступных в игре механик, видеть итоговые характеристики и планировать развитие своего персонажа.

# 🔍 **Основные Функции**:

-	Конфигурация персонажа: Выбор прокаченных навыков персонажа .
-	Конфигурация кораблей: Подбор снаряжения, ядер дляформирования итоговых характеристик.
-	Тестирование гипотез: Изменение параметров и просмотр, как это влияет на характеристики корабля.
-	Рассчёт навыков: Расчёт скилл-поинтов (SP) для управления разными классами кораблей, с возможностью просмотра улучшений по уровням.

# 🛠 **Технологии**:

-	UI написан на комбинации фремворков UIKit, SwiftUI. Для реактивного обновления применяется Combine. Для верстки используетя Auto Layout на основе ShapKit
-	Основная архитектура модулей приложения - MVVM для навигации используется Router
-	Проблемы многопоточности решены на основе Swift Concurrency
-	[Бэкенд](https://www.eveechoes.com](https://github.com/MickeyRU/Cosmic-Slipway-Backend)) написан на фраемворке VAPOR
